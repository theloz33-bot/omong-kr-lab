쿠팡 파트너스 고지

이 블로그에는 쿠팡 파트너스 활동의 일환으로 발급된 링크가 포함되어 있습니다. 해당 링크를 통해 상품을 구매하면 이 블로그 운영자에게 일정액의 수수료가 지급되며, 구매자가 지불하는 금액은 달라지지 않습니다.

쿠팡 링크가 들어간 글에는 아래 문구를 글마다 표시합니다.

이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

상품 가격과 할인율은 글을 쓴 시점에 확인한 값이며, 쿠팡의 정책과 재고에 따라 달라집니다. 최종 가격은 링크를 열어 확인해 주세요.

크몽 서비스 고지

영상 제작 의뢰 카드는 이 블로그 운영자가 크몽에서 판매하는 서비스입니다. 상담, 결제, 정산, 환불은 모두 크몽을 통해 이루어지며, 이 사이트는 카드 정보를 받지도 저장하지도 않습니다. 서비스 가격과 조건은 크몽에 등록된 내용이 기준입니다.

이 사이트가 수집하는 것

없습니다.

  • 분석 스크립트, 추적 픽셀, 세션 녹화를 쓰지 않습니다.
  • 쿠키를 쓰지 않으므로 동의 배너도 없습니다.
  • 회원가입, 댓글, 로그인 기능이 없습니다.
  • 외부 폰트나 임베드를 불러오지 않습니다. 페이지는 자체 CSS와 아이콘만 불러옵니다.

다만 상품 사진은 쿠팡 이미지 서버에서 직접 불러오며, 이때 접속 환경의 일반적인 요청 정보가 전달됩니다. 사진 요청에는 referrerpolicy="no-referrer"를 적용해 이 페이지 주소가 전달되지 않도록 했습니다.

사이트는 GitHub Pages가 정적 파일로 제공합니다. 어떤 웹 호스트든 페이지를 제공하는 과정에서 IP 주소를 포함한 표준 접속 기록이 남으며, 이는 호스트의 정책을 따릅니다.

결제와 환불

상품 구매의 결제·배송·교환·환불은 쿠팡이 처리합니다. 영상 제작의 결제·환불은 크몽과 판매자 규정을 따릅니다. 이 사이트는 두 서비스의 주문 정보를 보관하지 않습니다.
